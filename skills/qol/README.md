# QoL

Quality of life: small skills that save time every day, on any project.

| Skill | Use it when |
| --- | --- |
| [charles-eli14](charles-eli14/) | You want something explained clearly, the way a great teacher would explain it to a sharp 14-year-old |
| [charles-learn-anything](charles-learn-anything/) | You want to properly understand a topic in a few minutes: a narrated lesson with demos and quick checks, in Chrome |
| [charles-storage-cleanup](charles-storage-cleanup/) | Your Mac is out of space and you want to know what's safe to delete |

Install one with `npx skills add LemonFace0309/charles-skills --skill <name>`, or the whole shelf in Claude Code:

```text
/plugin install qol --marketplace LemonFace0309/charles-skills
```
