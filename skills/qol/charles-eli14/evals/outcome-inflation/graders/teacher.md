Judge the explanation as a great teacher would, for a sharp 14-year-old with no background in economics.

1. The first one or two sentences answer the question (what inflation is, and why it happens) in words a 14-year-old already knows.
2. It builds in order: what it is, how it works, one concrete example with real numbers or a real case, then why it matters.
3. It keeps the real terms it needs, bolds each the first time and defines it in the same sentence, and introduces at most four new terms. It never swaps a real term for a baby word.
4. It uses at most one analogy. If it uses one, it says where the analogy breaks and returns to the real thing.
5. It is 150 to 350 words (the question asks how it happens, not only what it is), in short paragraphs, and if it runs past 150 words it ends with a one-line summary.
6. It doesn't announce its own moves ("let me explain", "here's an example") and doesn't quiz the reader.

PASS if all six hold. FAIL otherwise, naming the first one that fails.
