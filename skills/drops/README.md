# Drops

Specialist skills that each go deep on a single craft. charles-ux-animation is the most requested skill I have: people
have commented MOTION for it more than 4,000 times.

| Skill | Use it when |
| --- | --- |
| [charles-ux-animation](charles-ux-animation/) | Your interface works but doesn't feel good yet: taps, menus, modals and page changes that should move with intent |
| [charles-hero-mockups](charles-hero-mockups/) | You want to see a landing page's look before you build it, or pitch a client three art directions as finished images |
| [charles-design-tips](charles-design-tips/) | Your screen works but looks thrown together: long text centred, grey greys, one heavy shadow, buttons labelled Submit and empty states with nowhere to go |
| [charles-design-laws](charles-design-laws/) | A screen or flow feels confusing or cluttered: too many choices, groups that don't read as groups, nothing that says what to do next |
| [charles-create-posters](charles-create-posters/) | You want a poster people share for a company, brand or project: one witty picture that could only be that subject, with the art direction of Quartr's posters (earnings details only when you ask) |

Install one with `npx skills add LemonFace0309/charles-skills --skill <name>`, or the whole shelf in Claude Code:

```text
/plugin install drops --marketplace LemonFace0309/charles-skills
```
