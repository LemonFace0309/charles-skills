# Design

The skills I use on my own apps: first make a screen look designed, then make it feel finished.

| Skill | What it does |
| --- | --- |
| [charles-unslop](charles-unslop/) | Turns UI that looks AI-made into a designed screen with its own point of view |
| [charles-polish](charles-polish/) | Takes UI that works and fixes the details and motion, checked frame by frame |
| [charles-unreasonable-craft](charles-unreasonable-craft/) | Holds a site or app design to the bar of an Awwwards Site of the Day and an Apple Design Award |
| [charles-store-screenshots](charles-store-screenshots/) | Designs App Store screenshot sets and renders them at Apple's exact sizes |

Install one with `npx skills add LemonFace0309/charles-skills --skill <name>`, or the whole shelf in Claude Code:

```text
/plugin install design --marketplace LemonFace0309/charles-skills
```
