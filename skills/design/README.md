# Design

The skills I use on the apps I build: first make a screen look designed, then make it feel finished.

| Skill | Use it when |
| --- | --- |
| [charles-unslop](charles-unslop/) | A screen looks AI-generated and you want it to look designed |
| [charles-polish](charles-polish/) | The UI works but feels off, and it needs a last pass on states, spacing, contrast and motion |
| [charles-color-analysis](charles-color-analysis/) | Your colours clash, look muddy or just feel off, and you want exact fixes with before/after previews |
| [charles-unreasonable-craft](charles-unreasonable-craft/) | A site or app screen has to wow people, held to the bar of an Awwwards Site of the Day |
| [charles-store-screenshots](charles-store-screenshots/) | You need App Store screenshots that make people stop scrolling, rendered at Apple's exact sizes |

Install one with `npx skills add LemonFace0309/charles-skills --skill <name>`, or the whole shelf in Claude Code:

```text
/plugin install design --marketplace LemonFace0309/charles-skills
```
